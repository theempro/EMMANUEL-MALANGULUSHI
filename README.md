# 🛡 CyberShield — Personal Cybersecurity Dashboard

A real-time cybersecurity dashboard that helps users monitor password strength, detect data breaches, and analyze suspicious activity — all in one place.

---

## 🚀 Features

* 🔐 **Password Analyzer**

  * Real-time strength analysis using zxcvbn
  * Crack time estimation
  * Requirement validation

* 📧 **Data Breach Checker**

  * Simulated breach detection (upgrade-ready for real APIs)
  * Detects compromised accounts instantly

* 📊 **Security Score System**

  * Dynamic score (0–100)
  * Based on password strength, breaches, and activity

* 📡 **Activity Monitor**

  * Tracks login attempts by location and device
  * Simulated suspicious activity detection

* 🔑 **2FA Authentication Simulator**

  * Rotating 6-digit secure codes
  * Countdown timer verification system

* 🌍 **IP & Network Tracker**

  * Displays real IP, location, ISP, timezone
  * Powered by ipapi.co

* 🔐 **Password Generator**

  * Custom length (8–32 characters)
  * Includes symbols, numbers, uppercase/lowercase

* 🧠 **Smart Security Recommendations**

  * Personalized advice based on your security score

---

## 🧮 Security Score Formula

Security Score =
(Password Score × 30%) + (Breach Score × 40%) + (Activity Score × 30%)
